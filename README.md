# Одиночество (Смерть)
Если вокруг живой клетки меньше двух живых соседей, она погибает. Ей не с кем взаимодействовать.

# Перенаселение (Смерть)
Если вокруг живой клетки больше трех живых соседей, она погибает от нехватки ресурсов и тесноты.

# Стабильность (Выживание)
Если вокруг живой клетки находятся ровно два или три живых соседа, она продолжает жить и переходит в следующее поколение.

# Размножение (Зарождение жизни)
Если на пустом (мертвом) месте собираются ровно три живых соседа, в этой клетке зарождается жизнь. В следующем кадре она становится живой
